# 泛型约束 where\n\n## 一、核心本质\n\n**泛型约束** = 限制泛型 T 的类型范围。\n\n- 不加约束：T 可以是任意类型\n- 加约束：编译器知道 T 的能力，可调用方法 / 实例化\n\n## 二、四大约束（必考）\n\n### 1. 引用类型约束 `where T : class`\n\nT 必须是类、string、接口等引用类型。\n\n```csharp\nvoid Test<T>(T obj) where T : class { }\n```\n\n### 2. 值类型约束 `where T : struct`\n\nT 必须是结构体、int、double 等值类型。\n\n```csharp\nvoid Demo<T>(T num) where T : struct { }\n```\n\n### 3. 接口 / 父类约束 `where T : 接口名`\n\nT 必须实现接口/继承父类，可调用接口方法。\n\n```csharp\nvoid Work<T>(T t) where T : IWork { t.DoWork(); }\n```\n\n### 4. 无参构造约束 `where T : new()`\n\n允许 `new T()` 创建对象。\n\n```csharp\nT CreateInstance<T>() where T : new() { return new T(); }\n```\n\n## 三、多约束组合\n\n顺序固定：`父类/接口` → `class/struct` → `new()`\n\n```csharp\nclass Test<T> where T : IWork, class, new() { }\n```\n\n## 四、背诵总结\n\n1. class = 引用类型，struct = 值类型\n2. 接口约束 = 可调用方法，new() = 可实例化\n3. 约束可组合，顺序不能乱\n\n## 五、练习\n\n**需求：** 写泛型类约束 T 为引用类型 + 实现 Iword 接口 + 无参构造\n\n```csharp\nclass Person<T> : Iword where T : class, Iword, new()\n{\n    public void Out() { }\n}\nclass Boy<T> : Person<T> where T : class, Iword, new() { }\n```\n\n> 注意：子类继承时也需要复写泛型约束！", "file_path": "E:\\VitePress\\unity-blog\\docs\\CSharp\\generic-constraints.md"}

# 里氏替换原则

## 一、核心本质

**里氏替换原则** = 子类必须能够替换掉父类，程序逻辑不发生改变。

核心代码写法：**父类引用指向子类对象**，是多态的核心基础，面向对象设计的六大原则之一。

## 二、核心规则（铁律）

1. 子类可以扩展父类的功能，但**不能改变父类原有的功能**
2. 父类能出现的地方，子类一定能出现
3. **反向不成立**：子类引用不能指向父类对象
4. 接口 / 抽象类完全适用里氏替换

## 三、标准代码写法

```csharp
// 父类
class Person { }

// 子类
class Student : Person { }

// ✅ 里氏替换（正确）
Person p = new Student();

// ❌ 错误（子类引用指向父类，编译报错）
// Student s = new Person();
```

## 四、核心作用

1. 实现**多态**的基础
2. 增强程序的**可扩展性、可维护性**
3. 遵循面向对象的设计规范

## 五、背诵总结

1. 核心：父类引用指向子类对象
2. 子类可替换父类，不改变原有逻辑
3. 多态的根基，接口/继承通用
